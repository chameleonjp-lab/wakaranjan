# ワカランジャン 役一覧 v0.1

## 1. 目的

この文書は、解説・問題・用語集・点数計算機が共通して参照する役の対象範囲を定義する。

役名、読み、翻数、門前限定かどうか、鳴いた場合の翻数、成立条件を実装時に共通データ化する。

|---|---|---|
| 立直 | リーチ | 門前・テンパイで宣言 |

## 3. 2翻役

| 役 | 読み | 条件の要点 |
|---|---|---|
| ダブル立直 | ダブルリーチ | 第一巡の条件を満たしてリーチ |
| 三色同順 | サンショクドウジュン | 3種類の数牌で同じ並びの順子 |
| 一気通貫 | イッキツウカン | 同一種類で123・456・789 |
| 混全帯么九 | チャンタ | すべての面子と雀頭に么九牌を含む |
| 七対子 | チートイツ | 異なる対子7組 |
| 対々和 | トイトイ | 4面子すべて刻子・槓子 |
| 三暗刻 | サンアンコウ | 暗刻・暗槓を3組 |
| 三色同刻 | サンショクドウコウ | 3種類の数牌で同じ数字の刻子・槓子 |
| 三槓子 | サンカンツ | 槓子3組 |
| 小三元 | ショウサンゲン | 三元牌2刻子と1雀頭 |
| 混老頭 | ホンロウトウ | 一九牌と字牌だけ |

鳴いた場合に翻数が下がる役は、共通データで門前時と副露時を別に持つ。

## 6. 特殊形・ダブル役満の扱い

次のようなダブル役満扱いは、標準問題では独立した2倍役満として扱わず、「ルール差」として解説する。

- 国士無双十三面待ち
- 四暗刻単騎
- 純正九蓮宝燈
- 大四喜のダブル役満扱い

役満同士の複合は標準ルールで認める。

## 7. ドラ

ドラは役ではない。

次を追加翻として別管理する。

- 表ドラ
- 裏ドラ
- 槓ドラ
- 槓裏ドラ
- 赤ドラ

ドラだけではあがれないことを、入門・初級で明示する。

## 8. ローカル役

次のようなローカル役・古役は標準役一覧には含めず、特例ページでのみ紹介する。

例:

- 人和
- 大車輪
- 大竹林
- 大数隣
- 十三不塔
- 八連荘
- その他、採用場所が限定される役

## 9. 実装時に各役が持つべき情報

- `id`
- 日本語名
- 読み
- 英字識別名
- 門前時翻数
- 副露時翻数
- 役満倍率
- 門前限定か
- 成立条件
- 同時成立しない役
- 成立例
- 不成立例
- 学習段階
- 標準採用か
- 関連用語

この文書は役の対象範囲を固定するものであり、最終的な成立判定ロジックは自動テストで検証する。
