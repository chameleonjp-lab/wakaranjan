# ワカランジャン 点数計算 検査項目 v0.1

## 1. 目的

点数計算機、点数問題、対局練習が同じ結果になることを保証するため、実装前に必須検査項目を固定する。

## 2. 基本計算

最低限、次を自動検査する。

- 20符〜110符の標準的な符計算
- 1翻〜13翻以上
- 親ロン
- 子ロン
- 親ツモ
- 子ツモ
- 100点単位への切り上げ
- 満貫
- 跳満
- 倍満
- 三倍満
- 役満
- 切り上げ満貫
- 数え役満を採用しない上限処理

## 3. 符の内訳

### 基本
- 副底20符
- 門前ロン加符10符
- ツモ符2符

### 雀頭
- 三元牌
- 自風牌
- 場風牌
- 連風牌
- 連風牌は2符。自風と場風が同じ場合も4符にしない
- 符の付かない雀頭

### 刻子・槓子
- 中張牌の明刻
- 中張牌の暗刻
- 么九牌の明刻
- 么九牌の暗刻
- 中張牌の明槓
- 中張牌の暗槓
- 么九牌の明槓
- 么九牌の暗槓

### 待ち
- 両面待ち
- 双碰待ち
- 嵌張待ち
- 辺張待ち
- 単騎待ち

## 4. 特殊な符

- 七対子25符固定
- ピンフツモ20符
- 門前ピンフロン30符
- 鳴いた平和形の最低符処理
- 符計算後の10符単位切り上げ

## 5. あがり牌による判定差

同じ13枚でも、あがり牌によって結果が変わるケースを検査する。

- 両面と嵌張が変わる
- 双碰で刻子が完成する
- ロンによって暗刻扱いにならない刻子
- ツモなら暗刻になるケース
- 三暗刻の成立・不成立
- 四暗刻の成立・不成立

## 6. 役と符の相互作用

- ピンフ成立時の待ち・雀頭確認
- 七対子と通常形の両方に取れる手
- 複数の面子分解がある手
- 分解ごとに役・符・点数が異なる手
- 最も高い点数の分解を採用すること
- 同点の別分解を許容すること

## 7. ドラ

- 表ドラ
- 裏ドラ
- 槓ドラ
- 槓裏ドラ
- 赤ドラ
- 同一牌に複数ドラが重なるケース
- ドラだけで役なしの場合はあがれない
- 赤5と通常5を区別しつつ、物理枚数は合計4枚以内

## 8. リーチ関連

- 門前時のみリーチ可
- 副露手でリーチ不可
- 一発
- ダブルリーチ
- リーチ後の裏ドラ
- リーチ棒
- リーチ後見逃しフリテン

## 9. フリテン

- 自分の捨て牌に待ち牌がある
- 複数待ちの一部だけを捨てていてもロン不可
- 同巡内フリテン
- リーチ後見逃し
- フリテンでもツモあがりは可能

## 10. カン

- 暗槓
- 大明槓
- 加槓
- 槓子の符
- 槓ドラ
- 槓裏ドラ
- 嶺上開花
- 搶槓
- 槓後の牌枚数整合性

## 11. 役満

各標準役満について、最低1件の成立例と1件の不成立境界例を用意する。

- 天和
- 地和
- 国士無双
- 四暗刻
- 大三元
- 小四喜
- 大四喜
- 字一色
- 緑一色
- 清老頭
- 四槓子
- 九蓮宝燈

さらに次を検査する。

- 役満複合
- 標準ではダブル役満として扱わない特殊形
- 通常役・ドラを役満点に追加しない処理

## 12. 本場・供託

- 0本場
- 1本場
- 複数本場
- ロン時の本場加算
- ツモ時の各家への本場加算
- 供託リーチ棒

## 13. 入力異常

計算を拒否し、理由を表示するケース。

- 牌が不足
- 牌が過剰
- 同一牌が5枚以上
- 赤牌と通常牌を合わせて5枚以上
- 副露の形が不正
- カンを含む総牌数が不正
- あがり形ではない
- 役なし
- 副露状態と門前役指定が矛盾
- ロン指定だがフリテン
- 同時成立不能な特殊状況

## 14. 点数境界

特に境界値を独立テストする。

- 30符4翻
- 60符3翻
- 70符3翻
- 40符4翻
- 20符5翻
- 満貫到達直前と到達後
- 跳満・倍満・三倍満の境界
- 13翻以上の三倍満上限制御

## 15. 教材との一致

すべての点数問題は、手書きの正解値を唯一の根拠にしない。

共通点数計算機で再計算し、次が一致することを検査する。

- 成立役
- 翻
- 符
- 基本点
- 最終点数
- 親子
- ロン / ツモ支払額

## 16. 検査データ管理

各テストケースに次を持たせる。

- ID
- 目的
- 手牌
- 副露
- あがり牌
- 局面条件
- 期待する役
- 期待翻
- 期待符
- 期待点数
- 期待エラー
- 参照ルール版

実装後は、ルール判定コードを変更するたびに全ケースを再実行する。
