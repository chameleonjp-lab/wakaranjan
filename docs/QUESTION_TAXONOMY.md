# ワカランジャン 問題分類 v0.2

## 1. 目的

問題数が増えても、出題内容・正解判定・難易度・復習が崩れないように、問題を共通分類する。

## 2. 大分類

| 分類ID | 分野 | 主な回答形式 |
|---|---|---|
| TILE | 牌名・読み | 一択、牌タップ |
| GROUP | 面子・雀頭 | 一択、複数、並べ替え |
| WINFORM | あがり形 | 一択、複数 |
| WAIT | 待ち牌 | 牌タップ、複数選択 |
| RON | ロン可否 | 一択、複数選択 |
| CALL | チー・ポン・カン | 手順、牌選択 |
| RIICHI | リーチ可否・判断 | 一択 |
| FURITEN | フリテン | 一択、卓上判断 |
| YAKU | 役 | 一択、複数選択 |
| HAN | 翻 | 数値、一択 |
| FU | 符 | 数値、内訳選択 |
| SCORE | 点数 | 数値、一択 |
| TABLE | 卓全体状況 | 卓上判断 |
| EFFICIENCY | 牌効率 | 牌選択、比較 |
| DEFENSE | 守備 | 牌選択、比較 |
| RULE | ルール・特例 | 一択、複数 |
| COMPREHENSIVE | 総合 | 複合操作 |

## 3. 「待ち」と「ロン」の分離

`WAIT` は、手の形として完成する牌を答える。役・フリテンの有無は原則として問わない。

`RON` は、実際の局面でロン宣言が可能かを答える。役、フリテン、鳴き、状況役などを考慮する。

この2種類を同じ問題形式として混ぜない。

## 4. 難易度

- 入門: 1つの知識だけで答えられる
- 初級: 2〜3要素を組み合わせる
- 中級: 役・待ち・符など複数要素を扱う
- 上級: 複数解釈、例外、状況判断を扱う
- 特例: 採否がルールによって変わる内容

## 5. 回答形式

- `single_choice`: 1つ選ぶ
- `multiple_choice`: 正解をすべて選ぶ
- `tile_select`: 牌を選ぶ
- `tile_order`: 牌を並べる
- `numeric`: 数値入力
- `step_choice`: 手順を選ぶ
- `table_action`: 卓上を直接操作する
- `comparison`: 候補を比較する

牌を複数選ぶ問題は、`answerType: "tile_select"` と `interaction: "tile-pick"` を使い、`tileChoices` に選択肢、`answerTileCodes` に正解の牌を配列で持たせる。既存の `choices` と `answerIndex` も残し、文章表示・既存履歴との互換性を保つ。

一択問題は、生成・登録時に正解が本当に1つだけであることを検査する。

## 6. 問題データ必須項目

- `id`
- `schemaVersion`
- `rulesetVersion`
- `level`
- `category`
- `subCategory`
- `answerType`
- `prerequisites`
- `prompt`
- `state`
- `choices` または入力条件
- `correctAnswer`
- `explanation`
- `wrongAnswerNotes`
- `relatedLessons`
- `relatedTerms`
- `tags`
- `validationStatus`

## 7. 卓状態データ

必要に応じて次を保持する。

- 手牌
- あがり牌
- 副露
- 自分の河
- 他家の河
- ドラ表示牌
- 裏ドラ表示牌
- 場風
- 自風
- 親子
- 巡目
- ロン / ツモ
- リーチ状態
- 本場
- 供託
- 特殊状況

存在する牌は、赤牌を含めて物理的な枚数上限を超えないことを自動検査する。

## 8. 出題方法

単純な完全ランダムだけにしない。

優先順位の例:

1. 現在学習中の単元
2. 過去に間違えた問題
3. 未回答問題
4. 既に正解済みだが復習時期に来た問題

同一問題やほぼ同じ局面が連続しないようにする。

## 9. 自動生成向きの問題

- 牌の読み
- 面子判定
- 待ち
- あがり形
- 役判定
- 符
- 翻
- 点数

これらは、正解判定機能から問題を生成し、生成後にも同じ判定機能で検証する。

## 10. 人が作る問題

- マナー
- 初心者の誤解
- ルール差
- 戦術判断
- 説明文を読んで答える問題

戦術問題は、絶対的正解がない場合に `comparison` とし、「推奨」「条件による」を明示する。

## 11. 誤答時の必須表示

- 正しい答え
- 正解理由
- 選んだ答えが違う理由
- 関係する用語
- 関係する解説
- 同じ知識を確認する短い再問題

## 12. 問題品質検査

- ID重複なし
- 必須項目欠落なし
- 一択問題の正解は1つ
- 複数選択問題は全正解を列挙
- 手牌・河・副露・ドラ表示牌を含めて牌枚数が不可能になっていない
- 役判定が標準ルールと一致
- 点数問題が共通計算機の結果と一致
- 誤答解説が正解と矛盾しない
- 特例問題にはルール差表示がある
