# ワカランジャン 要件定義書

## 1. 目的

ワカランジャンは、麻雀を全く知らない中学生を中心に、日本式四人リーチ麻雀を段階的に学べる学習サイトとする。

最終的に、利用者が次の状態まで進めることを目標とする。

1. 麻雀牌を見分け、基本的な読み方を答えられる。
2. 一局の流れと、自分の番に行う操作を理解できる。
3. 基本的なあがり形、待ち、鳴き、リーチ、フリテンを判断できる。
4. 標準的な役を理解し、成立・不成立を判定できる。
5. 一般的な手の符・翻・点数を計算できる。
6. 難しい手は自動計算機で、役・符・点数の理由まで確認できる。

賭け、換金、課金、ガチャ、射幸性を目的とした設計は導入しない。

## 2. 対象利用者

- 麻雀経験がまったくない中学生
- ルールを一部だけ知っている初学者
- 役や点数計算を復習したい人
- 教材として利用する保護者・指導者

説明は専門語から始めず、最初に平易な説明を行い、その後に正式用語と読み方を示す。

## 4. 学習体験の基本

各解説ページは、原則として次の順番で構成する。

1. 今回できるようになること
2. 図を見る
3. 一手ずつ確認する
4. 解き方を一緒に確認する
5. 自分で解く
6. 誤答理由を確認する
7. まとめ

1ページで扱う内容を限定し、3〜7分程度で一区切りになる量を基準とする。

## 5. 図解

図はページごとの固定画像ではなく、共通の牌・卓表示部品から生成する。

最低限、次を表示できること。

- 手牌
- あがり牌
- 鳴き牌
- 河
- ドラ表示牌
- 場風・自風
- 親子
- 手番
- ツモ前後の変化

重要な違いは色だけで表現しない。

## 6. 問題設計

「待ち牌」と「実際にロンできる牌」は別の問題にする。

問題形式は次を許可する。

- 一択
- 複数選択
- 牌タップ
- 並べ替え
- 数値入力
- 手順選択
- 卓上判断

解答後は、正誤だけでなく、正解理由・誤答理由・関連解説を表示する。

問題はJSONで分割管理し、人が作る問題と自動生成問題を併用する。

## 7. 点数計算

点数計算機は、手牌だけでなく次の条件を入力できること。

- あがり牌
- ロン / ツモ
- 親 / 子
- 場風・自風
- リーチ等の宣言
- チー・ポン・各種カン
- ドラ表示牌
- 裏ドラ表示牌
- 赤牌
- 本場
- リーチ棒
- 海底・河底・嶺上・搶槓などの特殊状況

複数の解釈がある手は、すべての有効な分解を調べ、採用ルールの範囲で最も高い点数になるものを採用する。

結果は、役、翻、符の内訳、親子、ロン・ツモ別支払額を説明付きで表示する。

## 8. 学習記録

初期版ではアカウントを必須にしない。

端末内に次を保存する。

- 完了した解説
- 分野ごとの正答状況
- 間違えた問題
- 最後に開いたページ
- 表示・音・動きの設定

公開ランキングは初期要件に含めない。

## 9. スマートフォン・アクセシビリティ

- iPhone縦画面を基準にする。
- 横画面を強制しない。
- 長押し、二本指、ダブルタップを必須操作にしない。
- ドラッグ操作にはタップによる代替手段を用意する。
- 正誤を色や音だけで伝えない。
- 文字拡大で内容が欠けない。
- VoiceOver等で牌名と操作名を読み上げられる設計を目指す。
- 通常問題では制限時間を必須にしない。

## 10. 共通データ原則

牌、役、用語、標準ルール、点数計算基準は一か所で管理し、解説・問題・用語集・計算機・対局練習が同じデータを参照する。

ページごとに独自の役定義や点数表を持たせない。

- 複雑な検査と不具合調査: Luna / Max
