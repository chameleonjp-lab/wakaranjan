# 公開確認手順

## 自動確認

- `npm test` が成功する
- `npm run test:e2e` が成功する
- 64経路以上でJavaScriptエラーがない
- ホーム初回表示ではmanifestと標準ルール以外のJSONを取得しない
- 320・375・390・402・430pxでページ全体の横スクロールがない
- ツモと捨て牌、模擬東風戦、点数計算の主要操作が完了する
- 問題の回答、問題記録、教材進捗が保存される
- 破損した端末記録を初期値として扱える

## GitHub Pages確認

1. `Deploy GitHub Pages` の最新実行が成功していることを確認する。
2. 公開URLをプライベートブラウズで開く。
3. ブラウザの開発者向けエラーがないことを確認する。
4. ホームで大量のJSONを一括取得していないことを確認する。
5. 問題・用語集・点数計算・対局練習をそれぞれ開き、画面を再読み込みしても表示できることを確認する。

## iPhone Safari（実機）

iPhone 17 ProのSafariで、次を実際に操作します。

- ホーム、入門1-4・1-5
- 問題を1問回答し、学習記録を開く
- 点数計算で牌を選び、計算・全部消すを使う
- ツモと捨て牌、模擬東風戦を最後まで進める
- 設定で文字の大きさ・音・動きを変更し、再読み込みする
- 横向きにスクロールしても、ページ全体ではなく必要な牌列だけが動くことを確認する
- VoiceOver、文字拡大、キーボード表示中のボタン操作を確認する

不具合があれば、端末・Safariのバージョン、URL、再現手順、画面幅を記録してから修正する。
