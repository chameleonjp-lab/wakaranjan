# ワカランジャン

麻雀を知らない人が、牌を触りながら「ツモる・捨てる・役を作る・点数を確認する」順に学ぶ静的サイトです。学習記録と設定は、この端末のブラウザ内だけに保存します。

## 主な画面

- 教材：入門・初級・中級・上級・特例の38章
- 問題：文章問題と牌姿問題。正答記録は問題ID単位で保存
- 対局練習：ツモと捨て牌、鳴き、リーチ、フリテン、通し型練習、模擬東風戦
- 点数計算：牌姿・役・符・局面条件を共通計算処理で確認
- 用語集・役図鑑・標準ルール
- 家庭・先生向けの学習状況確認、印刷用教材、表示・音・動きの設定

## 開発時の確認

Node.js 22以上を使います。

```bash
npm test
npm run test:e2e
```

`test:e2e` はPlaywrightで静的サーバーを起動し、主要なハッシュ経路、320・375・390・402・430pxの表示幅、主要ボタン操作をChromiumで確認します。`npm run test:e2e:webkit` では同じ検査をWebKitでも行い、Safariに近い表示・操作経路を確認します。初回だけ検査用ブラウザのインストールが必要です。

## GitHub Pages公開

1. `fix/*` ブランチで変更を作る。
2. Pull Requestを作り、`Validate mahjong logic` を通す。
3. レビュー後に `main` へマージする。
4. `Deploy GitHub Pages` が検査と公開を行う。
5. 公開後に [公開確認手順](docs/PUBLISH_CHECKLIST.md)を実施する。

公開処理は、manifestのデータセット版をクエリに付けてJSONを読み込みます。ホームは必要最小限の教材一覧を先に読み込み、画面や章を開いたときは該当する本文・品質・問題データだけを読み込みます。

## リリース前のGitHub設定

`main` の保護と必須チェックは、リポジトリ設定画面で [GitHub設定手順](docs/GITHUB_SETTINGS.md)のとおりに設定します。設定後も、ブランチ画面で `protected: true` と必須チェックを確認してください。

最終的な公開判断は、独立レビューとユーザー本人の確認を経て行います。
